## 👩‍💻 Sobre mí

Soy **Power BI Developer / Data Analyst** especializada en transformar datos y necesidades de negocio en soluciones analíticas mantenibles, escalables y visualmente cuidadas.

Trabajo especialmente con el ecosistema **Microsoft BI**, desde el modelado y la lógica DAX hasta la construcción de informes, automatizaciones y soluciones alrededor de Power BI y Microsoft Fabric.

Me interesa especialmente todo lo que ocurre cuando **BI, desarrollo y automatización se cruzan**.

Actualmente dedico buena parte de mi tiempo a experimentar con:

- 🧠 **Modelado semántico y DAX avanzado**
- 📊 **Power BI y diseño de experiencias analíticas**
- ☁️ **Microsoft Fabric**
- 🎨 **Visualizaciones personalizadas con Deneb / Vega-Lite**
- ⚙️ **Automatización con Python y n8n**
- 🤖 **IA aplicada a Analytics y procesos de desarrollo**
- 🏗️ **TMDL, PBIP, Git y prácticas de versionado para Power BI**

> No me interesa hacer dashboards por hacer dashboards.  
> Me interesa construir productos de datos que sean **claros, mantenibles y útiles para tomar decisiones**.

## 💡 Mi forma de trabajar

```text
Entender el problema
        ↓
Entender el dato
        ↓
Diseñar el modelo
        ↓
Construir la lógica
        ↓
Diseñar la experiencia
        ↓
Automatizar lo repetitivo
        ↓
Medir, revisar y mejorar
```

Para mí, una buena solución de datos no acaba cuando el gráfico se ve bonito.

Debe ser:

**correcta · comprensible · mantenible · rápida · reutilizable**
